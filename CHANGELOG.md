## [1.0.0] - 2026-10-12

### Added

- Two-way skill sync with a three-way merge against the last synced version.
- Backups before any overwrite, kept for 30 days.
- User-scope MCP server sync, with secrets stripped and the home path templated.
- uv tool sync.
- Account plugin and connector check.
- Unattended `auto` mode, with per-machine status and log.
- Self-installing schedule for Windows Task Scheduler, launchd and cron.
- Claude Code plugin manifest.
